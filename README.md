# Pedra, Papel e Tesoura (Pygame)

Um jogo simples de **Pedra, Papel e Tesoura** (Jokenpô) desenvolvido em Python com interface gráfica feita através da biblioteca **Pygame**. 

Este projeto foi construído para praticar conceitos fundamentais de desenvolvimento de jogos 2D, manipulação de eventos, gestão de interface e lógica de programação em Python.

---

## Funcionalidades

- **Interface Gráfica Simples:** Janela interativa ($1200 \times 800\text{ px}$) com botões estilizados.
- **Placar Dinâmico:** Contagem de pontos do Jogador e do Computador em tempo real.
- **Centralização do Texto:** Cálculo de posicionamento automático para centralização de elementos gráficos.
- **Jogada Aleatória:** Lógica de escolha do adversário via módulo `random`.

---

## Tecnologias Utilizadas

- **Python 3**
- **Pygame**
